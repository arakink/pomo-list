# PomoFlowy

PomoFlowy は、ポモドーロタイマーと ToDo 管理をひとつにまとめた集中支援アプリです。

## Features

- 25分 `Work` / 5分 `Break` のタイマー
- ToDo の追加・編集・完了・削除
- 未完了タスクを現在の作業タスクとしてセット
- Work 完了時にタグ別の完了回数を集計
- `localStorage` による状態保存

## Main UI

- Timer Panel
- Current Task
- Tag Stats
- Todo Management

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Getting Started

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開くと確認できます。
